# Manual de Usuario - Bot de Telegram BecaRadar México

¡Bienvenido a **BecaRadar México**! Este bot de Telegram te ayuda a encontrar becas académicas vigentes en México de forma rápida y sencilla.

---

## 1. Cómo Iniciar

1. Abre Telegram y busca el usuario de nuestro bot: `@BecaRadarMX_bot`.
2. Presiona el botón **Iniciar** o envía el comando `/start`.
3. Recibirás un mensaje de bienvenida y el menú principal de comandos.

---

## 2. Comandos Disponibles

| Comando | Descripción | Ejemplo de Uso |
|---|---|---|
| `/start` | Muestra el mensaje de bienvenida y el menú principal. | `/start` |
| `/becas` | Lista las becas activas con filtros opcionales. | `/becas universidad` |
| `/buscar <texto>` | Búsqueda por palabras clave o institución. | `/buscar UNAM` |
| `/nivel` | Explora convocatorias filtrando por nivel educativo. | `/nivel preparatoria` |
| `/stats` | Consulta el total de becas disponibles en la base de datos. | `/stats` |
| `/ayuda` | Muestra la guía rápida y contacto de soporte. | `/ayuda` |

---

## 3. Preguntas Frecuentes (FAQ)

**¿El servicio tiene algún costo?**
No, BecaRadar México es un proyecto 100% gratuito y de acceso público.

**¿Las becas están verificadas?**
El bot recolecta información directamente de los portales oficiales (UNAM, IPN, Tec de Monterrey, Gobierno Federal). Cada beca incluye un enlace directo a la convocatoria oficial para que verifiques los detalles.
